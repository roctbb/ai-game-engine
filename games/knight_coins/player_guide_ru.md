# Конь собирает монеты

Напишите функцию:

```python
def make_move(x, y, board):
    ...
```

Она должна вернуть сдвиг коня: пару чисел `(dx, dy)`.

Например, `(2, 1)` означает прыгнуть на две клетки вправо и на одну вниз. Если хотите остаться на месте, верните `(0, 0)`.

## Цель

Соберите все монеты, а затем прыгните на выход.

Конь двигается как в шахматах: на две клетки по одной оси и на одну по другой. Он может перепрыгивать через клетки, но не может приземляться в стену или яму.

## Карта

Карта хранится как `board[x][y]`.

- `x` растет вправо;
- `y` растет вниз;
- `len(board)` - ширина;
- `len(board[0])` - высота.

Значения клеток:

- `-1` - стена или яма;
- `0` - пустая клетка;
- `1` - монета;
- `2` - выход.

## Разрешенные сдвиги

```python
MOVES = [
    (-1, -2), (1, -2),
    (2, -1), (2, 1),
    (1, 2), (-1, 2),
    (-2, 1), (-2, -1),
]
```

`(0, 0)` тоже разрешен, но очки начисляются за быстрый сбор монет, поэтому лучше ждать только если нет безопасного хода.

## Минимальный пример

```python
MOVES = [
    (-1, -2), (1, -2),
    (2, -1), (2, 1),
    (1, 2), (-1, 2),
    (-2, 1), (-2, -1),
]


def make_move(x, y, board):
    for dx, dy in MOVES:
        nx = x + dx
        ny = y + dy
        if 0 <= nx < len(board) and 0 <= ny < len(board[nx]):
            if board[nx][ny] != -1:
                return (dx, dy)
    return (0, 0)
```

## Идея сильного решения

Эту задачу удобно решать поиском в ширину.

1. Найдите все клетки с монетами `1`.
2. Если монеты есть, ищите BFS путь до ближайшей монеты.
3. Если монет нет, ищите BFS путь до выхода `2`.
4. Верните первый сдвиг из найденного пути.

Полный пример есть в `examples/bfs_knight.py`.
