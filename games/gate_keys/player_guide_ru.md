# Ключи и ворота

Напишите функцию:

```python
def make_move(x, y, board, keys):
    ...
```

Она должна вернуть одно из действий: `"up"`, `"down"`, `"left"`, `"right"` или `"stay"`.

## Цель

Соберите ключи, открывайте ворота и дойдите до выхода.

Один ключ открывает одни ворота и сразу тратится.

## Карта

Карта хранится как `board[x][y]`.

- `x` растет вправо;
- `y` растет вниз;
- `len(board)` - ширина;
- `len(board[0])` - высота.

Значения клеток:

- `-1` - стена;
- `-2` - закрытые ворота;
- `0` - пустая клетка;
- `1` - ключ;
- `2` - выход.

Параметр `keys` показывает, сколько ключей сейчас у робота. На клетку `-2` можно зайти только если `keys > 0`; после входа ключ тратится.

## Минимальный пример

```python
DIRECTIONS = {
    "up": (0, -1),
    "right": (1, 0),
    "down": (0, 1),
    "left": (-1, 0),
}


def make_move(x, y, board, keys):
    for action, (dx, dy) in DIRECTIONS.items():
        nx = x + dx
        ny = y + dy
        if 0 <= nx < len(board) and 0 <= ny < len(board[nx]):
            cell = board[nx][ny]
            if cell != -1 and (cell != -2 or keys > 0):
                return action
    return "stay"
```

## Идея сильного решения

Эту задачу удобно решать поиском в ширину, но состоянием должна быть не только позиция, а тройка `(x, y, keys)`.

1. Из текущего состояния попробуйте четыре соседние клетки.
2. Стены `-1` пропускайте.
3. Ворота `-2` разрешайте только при `keys > 0`, затем уменьшайте `keys` на 1.
4. Ключ `1` увеличивает `keys` на 1.
5. Ищите путь к выходу `2`; если ключей пока не хватает, BFS сначала найдет путь за ключами.
