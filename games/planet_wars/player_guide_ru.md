# Планетные войны

Захватите планеты соперников. Планеты производят корабли, а флоты летят между ними по прямой. В матче участвуют 2–4 команды; у каждой один слот кода.

## Первый бот

Определите `make_move(state)`. Верните список приказов или `[]`, чтобы подождать:

```python
def make_move(state):
    for source in state["planets"]:
        if source["owner"] != state["me"]:
            continue
        for target in state["planets"]:
            if target["owner"] is None and source["ships"] > target["ships"] + 5:
                return [{"from": source["id"], "to": target["id"],
                         "ships": target["ships"] + 1}]
    return []
```

На каждой своей планете можно отправить один флот за ход. Число кораблей — целое от 1 до текущего гарнизона. Некорректные приказы пропускаются. Все команды выбирают приказы по состоянию начала хода.

## Входные данные

| Поле `state` | Значение |
| --- | --- |
| `me` | Ваш цвет: `red`, `blue`, `green` или `yellow` |
| `tick`, `turns_left`, `max_turns` | Завершённые ходы, оставшееся время и лимит 300 ходов |
| `active_slots`, `alive` | Все команды и ещё не выбывшие команды |
| `planets` | Планеты: `id`, `x`, `y`, `owner`, `ships`, `production` |
| `fleets` | Флоты: `id`, `owner`, `from`, `to`, `ships`, `eta`, `duration` |
| `production`, `ships` | Словари суммарного производства и всех кораблей по командам |
| `speed` | Скорость флота: 6 единиц карты за ход |

`owner=None` означает нейтральную планету. `eta` — число ходов до прибытия. Готовая функция `travel_time(source, target)` принимает два словаря планет и возвращает `ceil(расстояние / 6)`, минимум 1. Менять приказ в полёте нельзя. Флоты не сражаются друг с другом в пути.

## Один ход

1. Все команды отдают приказы; корабли сразу вычитаются из гарнизонов.
2. Каждая принадлежащая команде планета добавляет `production` кораблей. Нейтральные ничего не производят.
3. Флоты сокращают `eta` на 1. Все прибывшие к одной планете флоты сражаются одновременно с её гарнизоном.

Силы одного владельца складываются. Сторона остаётся на планете, только если её силы **строго больше суммы всех остальных**; разница становится новым гарнизоном. Иначе планета нейтральна, гарнизон равен нулю. Нейтральный гарнизон — отдельная защищающаяся сторона. Правило одинаково для 2, 3 и 4 команд.

У каждой команды одинаковая домашняя планета: 45 кораблей, производство 3. Карта симметрична относительно поворота между стартами; на ней 14–16 планет. Значения нейтральных гарнизонов и производства меняются между матчами, но одинаковы для симметричных планет.

## Победа

Команда выбывает, когда не осталось ни её планет, ни флотов. Последняя оставшаяся побеждает. На лимите сравнивают производство, затем все корабли. Полное равенство означает ничью. Штрафов к результату за ошибки кода или приказов нет: бот просто пропускает действие, а ошибка кода видна в журнале.

## Что видно на поле

Цвет обозначает владельца, число в планете — гарнизон, `+N` — производство. Номер планеты помогает сопоставить поле с кодом. Подписи крупных флотов показывают корабли и оставшиеся ходы; подробности любого флота доступны при наведении. Сверху — производство и корабли команд.

Начните с ближайших нейтральных планет. Затем учитывайте производство противника за время перелёта, прибывающие подкрепления и резерв дома. Пространство переменных бота сохраняется между ходами; доступен `print()` для журнала.
