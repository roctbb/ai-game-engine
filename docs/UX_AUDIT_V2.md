# Проверка UX «Арены» — 11 ноября 2026

Дополнительный полный проход турниров за преподавателя, ученика и позднего зрителя в обоих режимах: [сквозной отчёт](TOURNAMENT_E2E_AUDIT_2026-11-11.md). В нём зафиксированы реальные матчи, финалы, архив, права на исходники и исправления, найденные во время прохода.

Проверка выполнена на собранном фронтенде и полном Docker-стеке в Colima, с изолированной копией серверной базы. Приложение: `http://127.0.0.1:5181`. Игровые запуски выполнялись настоящими scheduler/worker. Рабочая база сервера для проверки не изменялась.

Опорные документы: [граф переходов](UX_GRAPH_V2.md), [контракт экранов](UX_SCREENS_V2.md), [границы реализации](UX_IMPLEMENTATION_V2.md). Проверка включает компоновку и действия, а не только цвета.

## Маршруты и сохранённые действия

| Экран | Роли | Проверяемый сценарий |
| --- | --- | --- |
| Вход | Гость | Возврат по `next`, загрузка способов входа, ошибка сервиса и повтор запроса |
| Открытые лобби | Все | Состояние, число участников, подключение; каталог задач отсутствует у ученика |

| Разбор сохранённой попытки | Владелец, преподаватель, администратор | Автор и время, неизменяемый исходник, ошибка у файла и строки, «Новее / Старее», возврат с фильтрами |
| Лобби → игры | Все | Текущие матчи отдельно от истории; поиск по имени/времени, участник, даты, ошибки и страницы |

| Лобби → правила | Все | Условие и API без лишней боковой колонки |
| Лобби → код и поле | Участник | Сохранение перед очередью, готовность, переключение файла и условие; преподаватель участвует явно |
| Лобби → текущие матчи | Все с доступом | «Смотреть», выбор любого текущего матча, стрелки, разбор выбранного; без вступления зрителя в очередь |
| Лобби → архив | Все с доступом | Отдельные сохранённые турниры, результаты и любой доступный матч |
| Настройки и состав | Организатор | Центрированные диалоги, очередь / явный список, отмена и Escape |
| Турнир → матчи / сетка / таблица | Все с доступом | Все/свои матчи, фильтр участника, архив; команды раундов и модерация у организатора |
| Сохранённый матч | Все с доступом | Поле, управление повтором снизу, участники с первого кадра, полный экран и Escape |
| Исходник участника матча | Владелец / преподаватель | Снимок по времени, выбор разрешённого участника и файла, только чтение; свой код можно взять в работу |
| Отдельный код игрока | Владелец / преподаватель | Собственное сохранение или чужой неизменяемый код, возврат в исходный контекст |
| Документация игры | Все с доступом | Содержимое и возврат; без технических счётчиков файлов |

Совместимые переадресации `/workspace/:teamId`, `/runs/:runId`, `/competitions` не создают дополнительных экранов. Передача оценок, классы и занятия исключены по согласованным границам.

## Что исправлено при сверке

- В лобби отделены текущие матчи и прошедшая история. У обычной записи истории убрана плашка «Завершён»; ошибки выделяются отдельно. Сохранены фильтры при обновлении и возврате из разбора.
- Просмотр текущих матчей имеет один переключатель и одно игровое поле. В скрытых вкладках iframe больше не запускается. Полное публичное лобби доступно авторизованному зрителю без добавления в состав.
- Разбор попытки получил шапку с автором/временем, навигацию между попытками, время снимка и явное «только чтение». Ошибка заметна у файла, в левом поле редактора и над визуализацией.
- Обновления собственного запуска не подменяют открытую попытку ученика. Повтор поля из разбора возвращает собственный редактор. Незавершённая загрузка снимка не возвращает старый режим после выхода из разбора.
- В повторе матча управление перенесено под поле; повторяющиеся сводки заменены компактной таблицей. Состав виден до появления счёта; сущности карты не считаются игроками, старые имена сопоставляются с участниками без дублирования. Сохранены исходники, события, ошибки и технический перезапуск в меню.
- В турнире убраны крупные декоративные счётчики; вкладки вынесены отдельно, итоговая таблица занимает ширину страницы. Модерация осталась в меню участника.
- Компактные кнопки, select и меню имеют высоту 32 px, обычные — 36 px, мобильные — минимум 44 px. Исправлены контраст ошибочной строки кода и сообщения недоступного сервиса в тёмной теме.
- Поле крестиков-ноликов вписывается в высоту/ширину панели при открытии кода; служебные сообщения renderer скрыты. Escape передаётся из игрового iframe.

## Результаты и пределы проверки

Основная матрица: 296 представлений — 112 администратора, 104 преподавателя, 76 ученика и 4 гостя; светлая/тёмная темы, ширины 1440 и 390 px. После последних исправлений отдельно повторены 56 представлений кода, разбора, лобби и трансляции. На видимой области не обнаружены недостаточный контраст текста, горизонтальное переполнение документа, старые тени кнопок или ошибки JavaScript. Проверены снимки всех маршрутов и общая плотность; ключевые рабочие экраны дополнительно просмотрены в полном размере.

Отдельно проверены действия и состояния, которые не заменяются снимком страницы: переходы между попытками, возврат с фильтрами, неизменяемость кода, копирование с отменой, перемотка, Escape из iframe, переключение одновременных матчей, права ученика, центрирование диалогов, загрузка и ошибка входа.

Автоматические проверки: backend — 439 passed, 6 skipped; frontend — 38 passed; TypeScript и production build успешны. Сквозной сценарий на Docker проверяет реальный запуск задачи, ошибку, готовых ботов с активным зрителем, остановку новых матчей без зрителей, ручное продвижение двух раундов и сохранённый архив.

Ожидаемый 404 проверен отдельно на уже удалённом тренировочном запуске. История тренировок сохраняет существующее окно последних 30 матчей; результаты турниров хранятся отдельно. Проверка игровых полей использует реальные задачи, крестики-нолики и матч танков на восемь участников; проверены полный состав в истории и мобильном диалоге, а также просмотр учеником без чужих исходников; она не означает прохождение каждого игрового пакета с каждым возможным входом.
